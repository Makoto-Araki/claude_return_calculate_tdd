# 要件定義書 - 除算 (divide)

## 概要

クライアントが送信した2個の正の整数パラメータ `a`, `b` を除算(`a / b`)し、結果を返すエンドポイントを提供する。

## ユーザーストーリー

API利用者として、2つの正の整数の商を取得したい。それにより、クライアント側で除算ロジック(ゼロ除算チェックを含む)を実装せずに済む。

## 受け入れ基準 (EARS記法)

1. WHEN クライアントが `POST /calculate/divide` に正の整数 `a`, `b`(いずれも1以上の整数)を含む有効なリクエストを送信した場合、THEN システムは `result = a / b` を計算し `200 OK` で結果を返す SHALL。
2. WHEN `a` または `b` が正の整数でない(数値でない、欠落している、小数である、`0`である、または負数である)場合、THEN システムは `422 Unprocessable Entity` を返す SHALL。`b` が `0` の場合もこの正の整数バリデーションの一部として扱い、ゼロ除算専用のエラーは設けない。
3. WHEN `a`, `b` が正の整数であっても割り切れない場合、THEN システムは商を小数(float)として計算し結果を返す SHALL。

## スコープ外

- 3つ以上のオペランドの除算
- 無限小数の丸め仕様の詳細定義(Python標準のfloat精度に依存)
